# quiet-x

Read SPEC.md before changing the extension. Design tokens live at the top of styles.css. `npm test` runs the Playwright checks against local fixtures.

## Git commits

- Write commit titles like a person would: short, plain, direct.
- Keep titles under 50 characters, lowercase imperative ("fix login redirect").
- No prefixes like feat: or chore:, no emojis, no ending period.
- Say what actually changed. Avoid vague words like "update", "improve", "enhance".
- Most commits need only a title. Add a body only if the reason isn't obvious.
- Never add Co-Authored-By, "Generated with Claude Code", or session links.
- PR descriptions: a few plain sentences. No headers, checklists, or marketing tone.

Push every commit to GitHub `main` (`github` remote: https://github.com/nithinaru/quiet-x) and to `origin`.
